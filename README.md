# RB Meta Toggle

Небольшая утилита для macOS, которая показывает значок очков в строке меню и позволяет быстро подключать или отключать Ray-Ban Meta по Bluetooth.

## Возможности

- Левый клик по значку подключает или отключает выбранные очки.
- Правый клик открывает меню со статусом соединения, выбором сопряжённого Bluetooth-устройства и командой выхода.
- Выбранное устройство сохраняется между запусками.
- Значок становится зелёным при подключении.
- При неудаче или слишком долгом подключении приложение показывает причину в подсказке значка.

## Требования

- Mac с Apple Silicon.
- macOS 26 или новее.
- Очки должны быть предварительно сопряжены с Mac в настройках Bluetooth.

При первом запуске macOS попросит доступ к Bluetooth. Разрешите его, иначе приложение не сможет работать с очками.

## Использование

1. Откройте `RB Meta.app`.
2. Найдите значок очков в строке меню.
3. Нажмите левой кнопкой для быстрого подключения или отключения.
4. Нажмите правой кнопкой и выберите **«Выбрать устройство»**, если нужно указать другие очки.

## Сборка из исходников

В Terminal из папки проекта выполните:

```bash
swiftc RBMetaToggle.swift -framework Cocoa -framework IOBluetooth -o RBMetaToggle
cp RBMetaToggle "RB Meta.app/Contents/MacOS/RBMetaToggle"
codesign --force --sign - "RB Meta.app"
```

`Info.plist` уже содержит необходимое описание доступа к Bluetooth.
